🤔 常見疑問

最近在 AI Agent 的討論區裡，常看到 Playwright 跟 Webwright 這兩個字。

它們到底是什麼？是 Skills 技能嗎？有什麼應用情境？又有什麼特別功能？

💡 一句話先講清楚

Playwright 是「控制瀏覽器的自動化工具」，讓 AI Agent 能像人一樣操作網頁。

Webwright 是 Microsoft Research 提出的框架，讓 AI Agent 用終端機寫 Playwright 程式來完成網頁任務。

它們本身不一定等於 Skills，但很常被包裝成 Agent 的「網頁操作技能」。

兩顆引擎，各司其職

一個負責「動手操作」，一個負責「動腦規劃」——合起來才是完整的 Web Agent。

01

🎭 Playwright

控制瀏覽器的自動化工具

由 Microsoft 開發的開源自動化框架，支援多瀏覽器操作。

Chromium Firefox WebKit

主要應用情境

  • 網頁自動化測試
  • 爬蟲資料擷取
  • 自動化表單填寫
  • UI 自動化任務
  • 跨瀏覽器相容性測試

特色功能

  • 多瀏覽器支援
  • 自動等待（Auto-wait）
  • 強大定位能力（Locator）
  • 網路請求攔截與模擬
  • 並行測試與分頁管理
  • 支援多語言：Python / TypeScript / .NET / Java
02

🤖 Webwright

AI 驅動的瀏覽器任務代理框架

Microsoft Research 提出的創新框架，讓 AI Agent 能理解網頁並完成複雜任務。

自然語言 任務規劃 自動修正

主要應用情境

  • 自然語言 → 頁面操作
  • AI 自動化任務執行
  • 資訊擷取與自動化
  • AI Agent 網頁技能擴充
  • 企業內部流程自動化

特色功能

  • AI 自然語言理解任務
  • 自動生成 Playwright 程式碼
  • 任務規劃與執行
  • 任務執行回饋與自動修正
  • 可擴充為 Agent 技能模組
🧩

當 Playwright 搭配 Webwright

Playwright 負責「操作網頁」、Webwright 負責「想與規劃」—— 任務完成，結果更可靠！

Playwright 自動化初體驗

🎉 超開心！！

早上想到要讓 Agent 自動幫我判斷並填寫偵測到的、已定義好的 Google 表單欄位。 剛剛靠 Playwright 加上可隨時再擴充的 profile.json 檔， 已實作成功，超開心！！

1偵測欄位
2比對 profile.json 智慧判斷
3自動填入正確內容並送出
✓實作成功
profile.json　·　可隨時擴充的自動填表設定檔 
{
  "姓名": {
    "keys": ["姓名", "name"],
    "value": "王小明"
  },
  "信箱": {
    "keys": ["信箱", "郵件", "email", "電子郵件"],
    "value": "xiaoming@example.com"
  },
  "學校": {
    "keys": ["學校", "單位", "服務", "school", "organization"],
    "value": "○○國小"
  },
  "縣市": {
    "keys": ["縣市"],
    "value": "桃園市"
  },
  "職稱": {
    "keys": ["職稱", "職位", "職務", "title"],
    "value": "教師"
  },
  "電話": {
    "keys": ["電話", "手機", "phone", "mobile"],
    "value": "0912-345-678"
  },
  "心得或建議": {
    "keys": ["心得", "建議", "回饋", "想法", "意見", "feedback", "comment"],
    "value": "本次研習內容非常充實且實用，講師講解清晰，收穫良多，非常感謝主辦單位的用心安排！"
  }
}

💡 原理：表單上每個欄位的標題，會去比對 keys 陣列裡的關鍵字；命中就自動填入對應的 value。 想多填一個欄位？再加一組就好——不用改程式，只改設定檔。

填表的核心三行（概念示意） 
await page.goto(formUrl);
await page.locator('input[name="姓名"]').fill(profile["姓名"].value);
await page.locator('input[name="電子郵件"]').fill(profile["信箱"].value);
await page.locator('button[type="submit"]').click();   // ✅ 表單已送出
